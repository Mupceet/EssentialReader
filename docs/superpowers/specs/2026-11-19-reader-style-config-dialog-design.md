# 排版设置归一弹框（ReaderStyleConfigDialog）设计

- 日期：2026-11-19
- 状态：已与用户对齐四项关键决策，待实施
- 范围仓库：eink-lib 子模块（`modules/eink` feature/reader，模块侧自包含）
- 前置：契约 0.8.1 参数总账（id 46 / 目录 44 行）、0.8.2 立场修订（斜体支持、
  分隔线恢复、页脚字体通道先行）均已落地

## 1. 背景与问题

阅读排版参数已声明 46 个（目录协商 44 行），模块设置 UI 按功能汇聚为三个互斥弹框
（字体配置 / 信息配置 / 边距调整），由 `ReaderStyleDialog { Fonts, Info, Margin }`
枚举切换——**切换分类必须关闭当前弹框再从排版面板重开**。配置项增多后：

1. 跨分类调参（如「页眉字体 + 页眉边距」）往返成本高；
2. 只有按功能一种聚合视角，按信息区域（正文/标题/页眉/页脚）查参数无从下手；
3. 高频基本参数与低频高级参数混在同一层级，缺少分层配置的容器基础。

## 2. 目标与非目标

**目标**

1. 三弹框归一为单弹框，内部分类快速切换（不关闭重开）；
2. 弹框支持双聚合轴：按功能（字体/信息/边距）与按区域（正文/标题/页眉/页脚）；
3. 为「高级配置容器」定位奠定结构——后续预置模板/快捷入口以它为承载面。

**非目标（本轮明确不做）**

- 不新增任何参数设置行（含 0.8.2 已可用的斜体/下划线族/分隔线——另行批次上车）；
- 不做预置模板与首页快捷入口（方向 3，见 §7 占位）；
- 不改 VM 数据流、契约、宿主桥——纯模块 UI 容器重构。

## 3. 已对齐的四项决策

| 决策点 | 结论 |
|---|---|
| 容器形态 | **保持居中透明卡片**（四周透出正文实时预览；内容区内部滚动） |
| 参数上车范围 | **仅重构容器**，行集维持现状 |
| 双聚合轴交互 | **功能轴 Tab 切换 + 区域轴分组全景**（顶部聚合方式分段按钮；按功能 = Tab 行字体/信息/边距，按区域 = 锚点行 + 四分组滚动列表）。修订记录：初版两轴均为 Tab，因区域天然不等重（现状 9:2:6:6 行，全参数上车后约 16:10:7:7）——Tab 容器隐含「各页内容量相当」预期，标题 Tab 仅 2 行视觉单薄、正文 Tab 滚动过长，改为分组列表后不等重被结构性消解，锚点直达补回导航效率 |
| 入口收敛 | **保留三入口直达 Tab**（字体配置/信息配置/边距调整按钮不变，点击同一弹框并预选功能轴对应 Tab） |

## 4. 结构设计

### 4.1 组件层级

```text
ReaderScreen
  └─ styleDialog: StyleTab?（null = 关闭；Fonts/Info/Margin 供三入口直达）
       └─ ReaderStyleConfigDialog（归一弹框，居中透明卡片）
            ├─ 标题行「排版设置」+ ✕
            ├─ 聚合切换：[按功能] [按区域]（分段按钮两枚）
            ├─ 功能轴：Tab 行（字体│信息│边距）+ 对应内容区
            └─ 区域轴：锚点行（正文│标题│页眉│页脚，点击直达分组）
                 + 分组全景内容区（组标题 + 行，滚动呈现四组）
```

### 4.2 状态模型

- `enum class StyleAxis { FUNCTION, REGION }`
- 功能轴 Tab：`Fonts / Info / Margin`；区域轴分组：`Body / Title / Header / Footer`
- 弹框内状态（`axis` + 功能轴 `lastTab`）用 `rememberSaveable`：
  - 会话内记忆、防旋转/重建丢失；**不落盘**；
  - 三入口点击时重置为「功能轴·入口对应 Tab」；弹框内切轴回到该轴上次状态；
  - 关闭再开（经入口）按入口定位——跨打开位置记忆与直达语义冲突，不做；
  - 区域轴不记滚动位置——切入时回到列表顶部（锚点直达是区域轴的定位方式）。
- VM 零新增状态；行回调照旧走 `applyStyleChange` → 目录 diff → 重排/即时生效。

### 4.3 内容映射（行集不变，重新归组）

现状行清单（唯一事实源，实施时以此迁移）：

| 来源 | 行 |
|---|---|
| 排版面板（ReaderLayoutPanel） | 字号/字距/缩进/行距/段距 五滑条 + 三入口按钮行 |
| 字体配置弹框（ReaderFontConfigDialog） | 字体选择两级交互全套（系统预设/文件夹字体/示例预览） |
| 信息配置弹框（ReaderInfoConfigDialog） | 标题位置 / 标题字号 / 页眉显示 / 页脚显示 / 页眉页脚字号 |
| 边距弹框（ReaderMarginDialog） | 正文·四边距 / 页眉·四边距 / 页脚·四边距（现为三子 Tab） |

归一后：

| 视图 | 内容 |
|---|---|
| 功能轴·字体 Tab | 字体配置弹框全套原样迁入 |
| 功能轴·信息 Tab | 信息配置弹框 5 行原样迁入 |
| 功能轴·边距 Tab | 边距弹框 12 行滑条；**内部三子 Tab 改为「正文/页眉/页脚」三组分组列表**（消除双层 Tab） |
| 区域视图·正文组 | 排版面板五滑条 + 正文四边距 |
| 区域视图·标题组 | 标题位置 + 标题字号（信息弹框现有行；标题留白/行距暂无 UI 行，参数上车批次再入） |
| 区域视图·页眉组 | 页眉显示 + 页眉页脚字号（页眉侧）+ 页眉四边距 |
| 区域视图·页脚组 | 页脚显示 + 页眉页脚字号（页脚侧）+ 页脚四边距 |

注：

- 「页眉页脚字号」是同一拖动条统一写入两键（ReaderTextStyle 既有语义）——区域视图
  页眉/页脚组各自呈现该行（同一行组件两处复用，回调一致）；
- 行组件抽取为可复用私有 composable，功能轴与区域视图共享同一实现与回调；行的
  显隐照旧由 `catalog.available(id)` 门控，某分组行全不可用时**该组与其锚点一起隐藏**
  （目录驱动，现状口径）；四组全不可用（不可达）时区域视图呈现空态；
- 排版面板本身维持「五滑条 + 三入口」不变（五滑条是最常调参数留在首层，
  区域视图正文组是其冗余呈现，接受双入口）。

### 4.4 交互细节

- 切轴/切 Tab **不关闭弹框**（解决现状痛点）；功能轴切 Tab 重置滚动；
- 区域轴锚点行（正文/标题/页眉/页脚四枚分段按钮）点击**直达对应分组**——
  无动画直接跳（墨水屏刷新成本考量，不做 smoothScroll）；
- 区域轴分组标题常驻流内（非吸顶），滚动自然经过；锚点是唯一快速定位手段；
- 锚点行与功能轴 Tab 行同一位置同一控件形态（分段按钮组），语义随轴切换
  （功能轴 = 当前 Tab 高亮；区域轴 = 定位按钮，点击后短暂高亮目标组标题）；
- 该按钮行超过 4 项时横向可滚（沿 StyleEntryRow「一行多枚等宽按钮」先例；
  当前功能轴 3 项 / 区域轴 4 项，为后续参数上车预留）；
- 无障碍：功能轴 Tab 用 `Role.Tab`（边距弹框先例）、锚点按钮带「跳转到某组」
  可本地化语义、聚合切换分段按钮带选中态语义；
- 关闭交互沿用 EInkDialog：✕ / 卡片外空白点击 / 返回键；
- 实时预览：卡片居中四周透明不变；调参即时生效路径不变（纯绘制参数即时、
  affectsLayout 参数 200ms 防抖重排）。

## 5. 错误与边界

- 弹框打开期间目录为空（理论不可达：宿主恒返回目录）——回落 Fallback 目录，
  行显隐按回落目录口径（现状已如此）；
- 区域视图某分组行全不可用 → 该组与其锚点一起隐藏；四组全不可用（不可达）→
  区域视图空态（不伪造行）；
- `rememberSaveable` 丢失（进程回收）→ 回落功能轴·首个 Tab，无崩溃路径。

## 6. 测试

- 纯函数单测：轴模型、视图→行归组映射表、锚点↔分组对应表（含页眉页脚字号
  双呈现的幂等性、目录不可用时组/锚点同步隐藏）；
- 既有 462 模块测试不回归；ReaderStyleRouting、宿主桥、契约零改动（编译面不动）；
- 真机验收：三入口直达、切轴切 Tab 不关框、区域锚点直达分组、双轴内容一致性
  （同参数两轴同值）、实时预览、返回键/外点关闭、旋转后弹框状态保持。

## 7. 方向 3 占位（本轮不实现）

归一弹框定位为**高级配置容器**。预置模板 / 简化配置流程放首页快捷入口，后续
单独 spec 定义模板规范，至少覆盖：模板 = 参数快照子集 + 命名 + 应用入口 +
与完整模式阅读配置（ReadConfig 多套）的共存关系 + 模板来源（预置/用户自存）。
在模板规范定稿前，不在本弹框预留任何占位 UI。
