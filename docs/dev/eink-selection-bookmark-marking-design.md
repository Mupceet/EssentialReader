状态：v2 已实施（2026-09-10），待真机验证（v1 创建闭环已于同日实施完成）。
日期：2026-09-09（v1）/ 2026-09-10（v2 交互重设计）。

- 2026-09-10（用户确认，**v2 交互重设计，取代 v1 的创建闭环交互**）：
  - **选择即划线**：长按选择松手后自动记录为「划线」笔记（实线），不再经菜单显式保存。
  - 浮条三键【复制】【写想法】【删除】由**点按已有标记**唤起（划线 → 浮条）；
    点按**想法**（虚线）为浮窗（展示想法内容 + 同款三键，「写想法」即编辑）。
  - 类型语言：**划线 = 实线（underlineMode=1，note 空）；想法 = 虚线（underlineMode=2，
    note 非空）**。
  - **选择过程实时下划线预览**：拖拽调界时当前区间以实线划线样式实时重绘（取代灰色选区带），
    把手保留。
  - **跨页续选双向**：起始把手拖到页顶按住 → 翻上一页；结束把手拖到页底按住 → 翻下一页；
    翻页后选中「翻页边 → 手指位置」的内容，会话内可多次翻页，松手按完整章内区间落一条划线。
  - **书签改页面级交互**：顶栏按钮 + 阅读区下拉手势做**当前页书签 toggle**，自动记录
    （页位置 + 页文本为标题，无编辑弹层），页角标随快照下发。
  - **反馈最小化**：创建/删除/想法保存均无 toast（划线与虚线的呈现本身即反馈）；仅复制保留
    toast（剪贴板不可见需确认）。
  - 「复制」统一复制**划线选中的原文**。
- 2026-09-10（实施回填，v2）：三处实施精化——
  - 点按场景想法弹层的预览与提交携带 `findMarking` 的标记**完整原文**（跨行
    标记按 run 行内截段提交会同锚点不命中、另落重复记录）；松手场景仍为本地
    选区文本。
  - 落库后选区**冻结**：把手停用（只读展示），划线预览保留到重排新快照；调界
    仅发生在落库前（防跨锚点重复标记）。
  - 松手**不弹浮条**（下条「交互优化轮」修订）：松手只呈现划线本身，浮条一律
    由点按已有标记唤起。
  - 跨页续选的翻页归属采用**越出边归属**：空命中（拖出文本行盒）按越出边
    归属把手侧——页顶外 = 起始侧（向前）、页底外 = 结束侧（向后）；长按新建
    拖拽期同样判定，单页选区拖出页边按住即进入续选。
- 2026-09-10（实施回填，**交互优化轮**）：——
  - 松手落划线**不弹浮条**：落库是异步的，浮条键位会暴露落库时序（删除键
    要等宿主重排的新快照才能拿到 markingId）。改为一律「再次点按标记唤起
    浮条」，浮条键位恒为实心可用。
  - 冻结窗口保留划线预览：松手后只读选区保留到重排新快照到达（页变清态），
    避免预览先消失、正式划线后到的空档闪烁。
  - **点浮条外/点残留选区**：只收浮条（或清选区）并吞掉本次点按——不翻页、
    不唤操作条，从交互层消除「按钮消失→菜单收起后又冒出来」的幽灵浮条。

  - **切换条形态**（两轮真机反馈后定稿）：**无边框文字 Tab + 黑色下划线**
    （2026-09-12 改，真机反馈"顶部 Tab 实现方式太重"）——三段等宽、无外框
    无底色，常态文字次级灰 + 常规字重、选中文字正文黑 + **加粗** + 2dp 黑色
    下划线（宽度贴合标签文字）——选中态同时表达在文字与指示条上，与列表行
    "持久选中 = 标记 + 标题加粗"同源；段高 44dp、语义 `Role.Tab` + `selected`；
    行底保留 1dp 实灰结构线
    （§11）作 Tab 行与内容的分界，**下划线贴行底、盖住那段灰线**（整行只
    读成一条线：选中段黑、其余灰）——下划线漂在文字正下方会与结构线构成

    一枚 Tab 横跨 1/3 屏宽、高 44dp，翻黑过重；点 Tab 的反馈由内容区当帧
    整页切换承担，这类大组件只留 Selected 的黑色下划线。这正是
    DS 规范 §14 的
    `Tab: black indicator`——上一版"一体化分段控件"（1dp 外框 + 内分隔线 +
    选中段实心反白）属于规范里明确要避免的"大面积反色"。

    再触发那个压缩路径。

- 2026-09-12（真机反馈，**段首缩进不落墨迹**）：跨段选择时，中间段落段首
  那段空白也被铺了灰底、下划线（反馈「空白的区域不应该有」）。根因：段首
  缩进是**排版真实字符**（宿主 `paragraphIndent`，默认两个全角空格；见
  `ReaderChapterBlockMeasurer` 的 `bodyIndentText` / `leadingIndentItems`），
  行首即段首，跨段选区的中间段落 `from = 0` 正落在缩进上，按字符索引换算 x
  就把它算进了墨迹。修法：新增纯逻辑 `leadingIndentLength` / `inkRange`
  （模块 selection 包），**只改绘制起笔**——选区灰底（`selectionRuns`，带/
  把手/操作条锚点同源）与落库后的正式装饰（`decorationSpanX`，高亮带 +
  下划线）共用同一条「行首空白从句头剔掉」规则，两处不会再一有一无；区间
  本身仍按字符索引保存与落库（章内位置、选区文本、复制内容、宿主
  `book_marks` 数据不变）。整段区间全是空白时选区兜底按原区间呈现（否则
  选区没有视觉反馈、操作条也失去锚点），装饰侧则直接不落墨。
  **既定边界（用户确认，2026-09-12）**：完整模式渲染**不动**。同一标记在
  完整模式仍按元素 bounds 画（宿主 `ReaderPage.underlineRuns()`），段首空白
  上仍会有线——本项目原则是 e-ink 与完整模式的差异在模块内消化，不为对齐
  去改宿主 View 渲染链（排版/样式共享入口同理，见「两种模式共享
  ReadBookConfig」的既有语义）。后续复盘不要再提"顺手把宿主编排也改一下"。

- 2026-09-12（真机反馈，**跨页续选会话改章内两端点真值**）：症状是"能翻页，
  但一翻过去选中范围就飞、而且收不回来"。根因两条叠加：①翻页瞬间手指还
  停在页底（触发翻页的位置），下一次 move 把被拖端点映射到**新页末行**，
  于是选区瞬间铺满整页——这一步是设计里写明的"翻页边 → 手指位置"，本身没错；
  ②真正致命的是会话区间用 **min/max 单向累计**（旧 `ReaderSelectionSessionState`
  的 `bodyStart/bodyEnd`），累计只增不减，用户把手指往上抬想收到目标行时
  max 仍保留整页边界——「飞了且收不回来」。这套累计是为"翻页刷新窗口内旧页
  命中不污染极值"打的补丁，而补丁之所以必要，是因为模块把**页内命中**
  （行下标 + 行内字符）当成了选区真值，翻页后下标全部失效。
  改法（对齐完整模式 `ReaderSelection` 的 anchor/focus 口径）：新增纯逻辑
  `ReaderSelectionSession{startPos, endPos, draggingEnd}`——真值是**章内两端点**，
  拖动 = 给被拖端点赋值（可增可减），越界自动交换两端并翻转 `draggingEnd`；
  页内视觉每帧由 `[startPos, endPos)` ∩ 当前页推导；翻页边吸附保留但改成
  **赋值**（不再是取极值），所以手指往回收时区间跟着收。手势层新增
  `onDraggedHit` 把手指的**原始命中**上抛（会话按章内位置换算端点，不再从
  合成结果里比较"哪端动了"来反推侧别），会话进行中 `onSelectionChange` 的
  页内合成结果直接忽略。`segments`（页段文本累计）与 `joinSegments` 暂维持
  原样——那是跨页 `selectedText` 的拼接问题，与端点计算解耦；后续若要进一步
  收敛，可让宿主直接用 `(start, end)` 切章节正文，模块就不再需要页段累计。
  修复轮（同日真机反馈「翻到 N+1 页后光标停在页顶、再拖不动、最终只标到
  N 页」）：屏幕里有**两条**拖拽路径——把手拖拽（`ReaderSelectionOverlay`）
  与长按后直接拖（`detectDragGesturesAfterLongPress`）。首轮只给前者喂了
  `onDraggedHit`，后者仍只发页内合成结果，而会话期间页内合成被忽略，于是
  长按拖拽路径一翻页就**静默失效**（光标不动、端点不前进）。**两条路径都
  必须喂 `onDraggedHit`**；以后新增任何拖拽入口同样要接这条通路。
  再一轮（同日真机反馈「选中并向前翻页只选中翻页后的内容」）：当时把原因
  判成"缺了每次翻页重置被拖端"，于是加了 `draggingEnd = direction > 0`。
  **这一版已被推翻**：手指从抓起那一刻拖的就是**同一端**，翻页改侧会让"固定
  端"漂到远端——从 N 页 X 起选、下翻到 N+1 选到底、再拖回页顶翻回 N、继续
  拖到 X-10 时，实际会得到 [X-10, N+1 末] 而不是 [X-10, X]（与页内反向拖动
  不一致，真机反馈）。现规则：**翻页只记录方向** `lastFlipForward`（决定页变
  后被拖端吸附哪条边：下翻吸新页首行 = 与来页的接缝、上翻吸新页末行），
  `draggingEnd` **全程不变**，越过对端时照旧交换两端并翻转侧别（区间自然收敛
  成 [移动端, 固定端]）。原"向前翻页只选中翻页后的内容"由「触发带判定」一节的
  判据修订（改判"该方向还有没有可增长空间"）解决，与侧别无关。

- 2026-09-12（真机崩溃，**命中行内下标越界**）：`StringIndexOutOfBoundsException
  begin 0, end 11, length 6`，栈为 `buildSelection` ← `moveEndpoint` ←
  长按拖拽路径。原因：翻页刷新窗口里 `selection`（页内命中，行下标 + 行内
  字符）与 `page` 不同批更新——旧页命中落到当前页"行下标还在、行长已变"的
  那一行，`buildSelection` 直接 `substring(from, to)` 越界。两处修：①
  `buildSelection` 把端点行内下标**一律钳到行长**（行下标越界仍返回 null，
  行内越界按行尾钳制，选区退化为到行尾可继续用）——所有调用方一并受益；
  ② 会话进行中**跳过页内合成**（长按拖拽路径与把手拖拽路径都改），会话真值是
  章内两端点、页内结果本来就没人用，少一次越界机会也少一次白算。
- 2026-09-12（真机反馈，**同一手势内翻不回去**）：症状是"拖手柄能往回翻，
  但不抬手（长按拖拽同一手势）翻不回去"。根因是**闭包捕获过期值**：长按拖拽
  的 `pointerInput(selectionEnabled)` 闭包跨手势存活（不以 page/selection 为
  key，见 [ReaderScreen] 顶注），它内部读到的实时值必须经 `rememberUpdatedState`
  包一层；新增的 `session` 当时是**普通参数**，在手势开始那一刻被捕获成 null 并
  一直用，于是这条路径的翻页判据退化成旧的"只看把手侧"，而同一条规则在把手
  路径（overlay 内 `currentSession`）是生效的——所以只有手柄能翻回。修法：
  `val currentSession by rememberUpdatedState(session)`，长按路径两处引用改读它。
  **教训**：往这两条拖拽路径里加任何新的实时值（尤其是会话/页面这类手势中途
  会变的状态），必须同时包 `rememberUpdatedState`，否则只会在"手势开始时为
  null/旧值"的路径上静默失效。
- 2026-09-12（真机反馈，**笔记看得见、改想法保存失败**）：笔记 Tab 里能列出
  标记，点进去编辑想法保存时提示「保存失败」（宿主日志 `eink saveMarking:
  选区定位失败`）。根因是**文本口径不一致**：存锚点时 `SaveMarkingUseCase`
  会走 `BookContentProcessEngine.normalizeProcessText`，它**逐行 trim**——
  部分书源正文自带段首全角缩进会被裁掉；新建标记时模块提交的是**原文**（与
  正文逐字相等，能命中），而编辑已有标记时提交的是宿主存回来的**归一化文本**，
  与正文不再逐字相等 → `locateInContent` 的逐字搜索 + 全文唯一兜底全部失配
  → 报失败。标记本身能渲染，说明宿主渲染层的锚点解析
  （`BookContentProcessEngine.resolveRange`：按非空白字符序列匹配 + 就近提示位）
  是能处理的。修法：宿主桥新增 `locateSelectionInContent`——先走原逐字搜索
  （快路径不变），失配时改用**渲染层同一把尺** `resolveRange` 兜底，保证
  「能画出来的标记就一定编辑得了」。单测钉住：同一条正文上旧路径
  `locateInContent` 返回 -1、新路径给出起点；提示位漂移（超窗口）时也按就近
  命中纠偏。

## 1. 背景

宿主 MD3 阅读器的笔记为「划线体系」：`book_marks` 表，锚点 `TextProcessAnchor`
（chapterIndex / chapterPosition / selectedText / contextBefore / contextAfter /
normalizedTextHash）+ 样式 `TextProcessStyle`（underlineMode：1 实线 / 2 虚线 / 3 波浪 /
4 双线 / 5 SVG，bg 高亮，textColor 字体色）+ note 备注；保存后宿主重排当前章，标记经
ContentProcessor → 排版元素样式进入页面绘制。书签为 `bookmarks` 表，宿主有「当前页快速
书签」先例（页位置 + 页文本为标题，同页多条时删最近一条）与每页书签角标
（`ReaderPage.decoration.bookmarkBadge`）。

eink 模块（v1 已实施）：快照行携带章内位置桥（chapterPositions/top/bottom/decorations），
模块自持选择交互，经可选端口 `ReaderSelectionEngine` 落库。v2 在此基座上重设计交互：
选择即划线、点按再操作、跨页续选、页面级书签。数据与宿主同库同构，两模式互认。

## 2. 范围

目标：

- 点击式选择（v2.1）：拖动期灰底选中带 + 全长把手；松手保留选中并弹操作条
  （新区间 复制/想法/画线；已有标记 复制/想法/删除——**顺序固定，只有第三
  槽在「画线/删除」之间换**），动作明确选择后才落库。
- 跨页续选（双向：页顶按住向前、页底按住向后，会话内多次翻页）。
- 点按已有标记：划线/想法 → 同一三键操作条；想法键 → 预填编辑弹框（或
  划线转想法的新建弹层）。
- 书签页面级：顶栏按钮 + 下拉手势 toggle、页角标。
- 保留：页面装饰渲染（实/虚/波/双原生，SVG 降级实线，TEXT 不渲染）。

非目标（后续切片）：

- 书签/笔记列表查看与点击跳转。
- 划线样式配置（明示不做，见决策记录）。
- 向前翻页手势（阅读页翻页仍 next-only；跨页续选的「向前」指选区扩展方向）。
- 朗读/搜索/词典等其他宿主能力。

### 3.3 端口 `ReaderSelectionEngine`（v2 形态）

```kotlin
/**
 * 选区语义与批注落库端口：宿主负责锚点构造（上下文与哈希）并写
 * book_marks，提供页面级书签 toggle。模块不复制这些规则。
 *
 * 可选端口（同 appUpdateEngine 先例）：注册表缺失本端口时，模块降级——
 * 长按选择整体不启用（松手无动作、无浮条，选择交互无可用出路），
 * 下拉书签与顶栏书签钮隐藏，不做假死路径。
 */
interface ReaderSelectionEngine {

    /**
     * 保存标记（同锚点 upsert，创建/写想法/编辑想法复用）。
     * [ReaderSelectionCommit.thought] = false → 划线（实线，note 空串）；
     * true → 想法（虚线 + note）。虚线颜色取宿主默认，样式由宿主桥写入
     * TextProcessStyle（underlineMode 1/2）。
     * 宿主落库后自行触发当前章重排（保持页内位置），新快照经
     * onContentUpdated 携带装饰推送——模块不请求刷新。
     * false = 落库失败（模块提示「保存失败」并恢复现场）。
     */
    suspend fun saveMarking(commit: ReaderSelectionCommit): Boolean

    /**
     * 删除标记。false = 删除失败（模块提示并保留现场）。
     * 宿主删除后触发当前章重排（同 saveMarking 推送路径）。
     */
    suspend fun deleteMarking(markingId: String): Boolean

    /**
     * 读取标记详情（点按想法时浮窗展示与写想法预填）。
     * null = 标记不存在（换源清理等，模块按标记失效处理，不弹浮窗）。
     */
    suspend fun findMarking(markingId: String): ReaderMarkingDetail?

    /**
     * 当前页书签 toggle（宿主快速书签语义：同页已有多条时删最近一条）。
     * 自动记录：页位置 + 页文本为标题，无编辑层。
     * 宿主落库后触发当前章重排（角标随新快照推送）。
     * null = 无会话书；true = 本次添加；false = 本次移除。
     */
    suspend fun togglePageBookmark(): Boolean?
}

/** 标记详情（点按浮窗与写想法预填）。 */
@Stable
class ReaderMarkingDetail(
    /** 划线选中的原文。 */
    val selectedText: String,

    /** 想法内容（划线为空串）。 */
    val note: String,

    /** true = 想法（虚线）；false = 划线（实线）。 */
    val thought: Boolean,
)

/** 标记提交载荷。 */
@Stable
class ReaderSelectionCommit(
    /** 选区所在章节下标。 */
    val chapterIndex: Int,

    /** 章内字符区间 [start, end)（UTF-16、语义正文空间）。 */
    val start: Int,
    val end: Int,

    /** 选中文本（按行拼接、段落间隙以换行连接；跨页选区为跨页累计拼接）。
     *  宿主保存时以其在章节全文窗口搜索定位。 */
    val selectedText: String,

    /** 想法内容（划线为空串）。 */
    val note: String,

    /** true = 想法（虚线样式）；false = 划线（实线样式）。 */
    val thought: Boolean,
)
```

移除（v1 → v2）：`resolveSelection`（松手即存 + 点按走 findMarking 后无消费方）、
`saveBookmark`（书签改页面级 toggle）、`ReaderSelectionDraft`、commit 的
`bookmarkText`/`bookmarkContent` 字段。注册仍为可选端口。

### 3.4 位置口径

- 一律 **UTF-16 索引**，语义正文空间；标题行独立空间、无正文语义。
- 选区含标题行：不落划线（静默忽略，宿主同款约束）。
- **选区允许跨页**（v2）：章内区间跨页累计；跨页选中文本由模块按页段累计拼接
  （页边界若在段内则无分隔符，段落间隙以换行连接），宿主窗口搜索定位兜底。
  会话真值自 2026-09-12 起为**章内两端点**（`ReaderSelectionSession`：
  `startPos`/`endPos`/`draggingEnd`），页内命中只作渲染与命中载体——
  旧实现把真值放在页内命中 + min/max 单向累计，跨页后**收不回来**（见
  文首决策记录同日条目）。

### 3.5 数据流（v2.1，现行）

```text
长按/拖拽（模块本地：命中 → 选词 → 灰底选中带 + 两侧 pin 把手；页顶/页底按住翻页续选）
  └─松手──► 保持选中 + 弹操作条（**不落库**）
         ├─新区间三键【复制】【画线】【想法】
         │    ├─复制──► 剪贴板 + toast「已复制」，收操作条清选区
         │    ├─画线──► saveMarking(thought=false，黑色实线) ─► 宿主落库+重排
         │    │          └─► 选中带续显到装饰真的在页上，再清态（不闪断）
         │    └─想法──► 顶部大弹框 + 自动拉起输入法 ──保存──► saveMarking(thought=true, note)
         ├─已有标记三键【复制】【想法】【删除】（想法 = 编辑预填，删除按 id 即时可用）
         └─含标题选区只留【复制】（§3.4 不落划线）
      └─调界（按住把手）──► 操作条隐藏，抬手回到操作条
点按已有标记 ─► 命中 decoration.run（markingId 非空方为用户标记，空串为
                宿主高亮规则等非用户来源视为未命中）─► markingId
  └─划线/想法──► findMarking ─► 操作条三键【复制】【想法】【删除】
                  （与选区操作条同组件同语义）
        └─想法──► 顶部大弹框（**同一份**：已有想法预填 note，划线/新选区为空）
                   ──保存──► note 非空 = 想法（虚线）；清空 = 划线（实线）
点操作条外 ──► 收操作条（选区态另清选区）并吞掉本次点按（不翻页、不唤阅读菜单）
下拉/顶栏书签 ──► togglePageBookmark ─► 宿主落库+重排 ─► 角标随新快照刷新
```

## 4. 模块交互（v2 状态机）

选择状态完全在模块本地；宿主仅经端口收到落库/删除请求：

```text
阅读态 ──长按(系统 longPressTimeout，正文行上)──► 选词态
        命中测试：y → 行盒 top/bottom 定行；x → 行内逐字符宽度测最近字符
        选词：BreakIterator 词区间吸附（snapToWordRange）；触觉反馈一次
选词态/调界态 ──拖把手/拖手指──► 调界态：灰底选中带随区间变化重绘 + pin 把手
```

- 把手样式与完整模式一致（竖条贯穿行盒 + 下沿外挂圆点）：**手柄高度 =
  文本行高**，命中热区 28dp（以圆点为心）；把手命中优先于翻页手势；选区
  存在期间水平拖动手势不触发翻页。拖动期正文铺灰底（`selectionContainer`，
  2dp 圆角、垫在正文之下）。
- 拖动端越过另一端（实施精化）：端点允许交叉，区间按 `normalizeHits` 归一，
  但**固定端必须始终是不动的那一端**——每帧用 `draggingEndpointIsStart`
  按「拖动端 = 与命中位置一致的那一端」刷新被拖侧别；否则越过之后会把固定端
  当成被拖端，手指继续拖时对侧边缘跟着手指跑，选区越拖越乱（真机反馈）。
  把手拖拽与长按拖拽延伸两条路径同规则。
- 页顶/页底触发翻页的判定：被拖端点拖入页顶/页底触发带（首/末行行盒，各约
  一行高）并保持按住超过系统长按时值 → 翻页；一次按住只触发一次，翻页后需
  重新拖出再进触发带。归属规则（实施精化）：非空命中按把手侧判带（起始把手
  只判页顶、结束把手只判页底）；空命中（拖出文本行盒）按**越出边归属**——
  页顶外 = 起始侧、页底外 = 结束侧（会话内反向拖出页缘的双向翻页依赖此
  归属），行盒间空档不判触发、维持最近归属。长按新建拖拽期同样判定：
  单页选区拖出页边按住同样进入续选会话。
  **判据修订（2026-09-12，真机反馈「N 页翻到 N+1 页后翻不回 N 页」）**：
  会话存在时不再只看把手侧，改判**该方向上选区还有没有可增长空间**——
  被拖端进页顶带且对侧端在页外（更前）→ 上翻；进页底带且对侧端在页外
  （更后）→ 下翻。原因是翻页边吸附会把被拖端放到**对侧**页边（下翻后结束端
  贴在新页首行），只看把手侧永远给不出上翻。对侧端仍在本页时退回把手侧判据
  （收缩调界不误触）。实现见 `flipDirectionForDrag`，把手拖拽与长按拖拽
  两条路径共用。
  **吸附边规则（同日，真机反馈「翻回 N 页后拖到 X-10 却选到 N+1 那头」）**：
  页变后被拖端吸附哪条边**只由翻页方向定**（下翻吸新页首行、上翻吸新页末行，
  即"与来页的接缝"），**与把手侧无关**，且**不改被拖端**。被拖端全程是手指
  抓起的那一端；越过固定端时按 [ReaderSelectionSession.moveDragged] 交换两端
  并翻转侧别，区间自然收敛成 [移动端, 固定端]（与页内反向拖动一致）。
- 落库冻结（实施精化）：用户在操作条上选「画线/想法」后发起的落库即冻结
  选区——把手停用，选中带只读续显。退场门控（交互优化轮）：宿主重排推进
  `pageVersion` 后**只有当新快照真的带上该标记装饰**（按章内区间判交，见
  `markingRenderedForRange`——重排后行下标可能漂移，不能用行下标判）选中带
  才退场；装饰仍在途而区间未离页时按提交区间重锚续显，避免真机上「线先
  消失、再出现」的闪断（宿主重排可能先推一帧还没并入标记的页）。区间离页
  （翻页/跳章）或落库失败即清态——失败不留选中带冒充已落库。
- 松手弹操作条、不落库（v2.1）：动作副作用只发生在用户明确选择之后。原
  「松手即存」的删除键需要等宿主重排的新快照才能拿到 `markingId`（端口
  `saveMarking` 只回 Boolean），落库时序会暴露成键位「先禁用后可用」；
  改为点击式后从交互层消除该时序，键位恒为实心可用。
- 点操作条外收操作条（实施精化）：操作条/选区在场时阅读区点按只收它们并
  **吞掉本次点按**——不翻页、不唤阅读菜单（对齐完整模式 ReaderCanvasSurface
  选区外按下的 `suppressTap`）。穿透会把「收操作条」误读为翻页/菜单误触，
  且阅读菜单展开期操作条本就不组合，穿透后操作条状态会在菜单收起时复现成
  幽灵浮层。落库窗口内的残留选区同规则：点按只清选区并吞掉。
- 操作条为设计系统动作卡风格（`EInkShapes.large` 8dp 圆角 + 1dp 描边 +
  surface 实底，卡片内「上图标 24dp / 下文案」按钮，常态透明 + onSurface、
  按压反色、零动画直切，规范 §35）；点按已有标记场景 `findMarking` 的
  markingId 现成，三键恒可用。
- 操作条位置稳定（实施精化）：键序固定「复制、想法、画线（删除）」——前两槽
  在任何状态下不换位，只有第三槽随「选区是否落在标记上」替换，避免键位互调
  （真机反馈「按钮位置稳定一点」）；垂直侧别在一次展示内粘住（首选选区上方，
  放不下才到下方；定了之后选区微调不再上下翻面，那一侧真的放不下时才回落）；
  浮条随调界离场，下次展示重新判定。
- 下拉手势：竖直位移超阈值（约 80dp）且 dominant 方向为下 → toggle；与横向
  翻页、把手拖拽、长按选择互斥（无选区时才生效）。

## 5. 想法弹层

EInkDialog（设计系统 §20/§21，IME 避让由弹框自带 imePadding 承担）：

- 顶部只读预览选中文本（超长截断展示，落库不受影响）：松手场景取本地选区
  文本；点按场景取 `findMarking` 的标记**完整原文**（可跨行），不经快照
  命中 run 的行内截段——跨行标记按截段提交会同锚点不命中、另落重复记录
  （v2 Task 6 修复轮裁定）。预览不经端口二次解析。
- 想法输入框：**新建与编辑共用同一弹框**（v2.2），唯一差别是预填内容——
  编辑预填 `findMarking` 的 note，新建/划线转想法为空串；复制/删除在操作条
  三键上，弹框内不再重复放附加动作钮。
- 输入区**3 行起、6 行封顶并向上滚动**（v2.2）：想法写长时由输入区自身滚动，
  不把标题/预览/底部按钮挤走（真机反馈「内容被挤压」）；光标随输入由
  Compose 的 bring-into-view 沿滚动容器跟随。
- 保存/取消。保存 = `saveMarking(thought = note 非空, note)`——**内容决定
  类型**：非空 = 想法（虚线），清空（含仅空白）= 划线（实线），即想法把内容
  删空后保存自动变回划线，不产生「没有内容的虚线想法」；成功无 toast（装饰
  呈现即反馈），失败 tip「保存失败」弹层保留可重试。编辑场景提交选区以标记
  完整原文覆写 selectedText、同锚点 upsert。

- 下划线（v2.2 几何透传）：**绘制几何取宿主逐段透传的 `ReaderUnderlineGeometry`**

  线宽 1dp、偏移 2dp）。模式 1 实线 / 2 虚线 / 3 波浪 / 4 双线原生绘制，颜色走
  模块主题（黑）；模式 5 SVG 降级实线；TEXT 字体色效果不进装饰数据。
  早期模块自拟「基线下方 12% 行盒高」与宿主有明显落差（真机反馈「线离文本
  底部太近」），故改为透传。
- 高亮带：主题灰底色；合并（markingId + 样式分组）在宿主映射器执行，模块直绘。
- **选区灰底带**：调界态按 runs 逐行铺 `selectionContainer` 填充矩形（行盒高 ×
  行内区间宽、2dp 圆角），随拖拽逐帧重绘（模块本地，零宿主开销）；该层垫在
  页画布**下方**（正文笔迹压在带上仍可读），pin 把手叠在其上。底色取**中浅灰**
  （日间 #AAAAAA / 夜间 #555555）——首版 gray100(#DDDDDD) 在真机白底上几乎
  看不出选中（实测反馈「灰底太浅」），再深则压住正文。落库后的划线是页画布
  装饰（不参与布局），与选中带交接时不产生几何差。
- 刷新成本：装饰与选中带均走模块画布本地重绘；落库后的确认刷新随宿主重排整页一次。

## 7. 宿主 bridge 实现

- **映射器**：装饰提取按 markingId + 样式签名分组合并（不同标记不并入同一 run）；
  拷贝 `page.decoration.bookmarkBadge` 进快照。
- **saveMarking**：锚点构造同 v1（48 字上下文 + 哈希 + 窗口搜索定位；先提示位
  精确、后窗口回搜，定位不到视为选区失效从严返回 false），
  `thought` → underlineMode 1/2；复用 `SaveMarkingUseCase.save`（同锚点原地更新承担
  写想法转换/编辑）；成功后 `ReaderEngineImpl.relayout()` 推送。
- **deleteMarking**：按 id 删 `book_marks`（gateway/DAO delete）+ relayout。
- **findMarking**：按 id 读 gateway → `ReaderMarkingDetail`（selectedText/note/thought
  由 anchor.selectedText、note、style.underlineMode 推导）。
- **togglePageBookmark**：宿主快速书签语义（当前页无则加——页位置 + 页文本为
  标题、剔除排版占位符；有则删离当前阅读位置最近的一条）+ relayout（角标
  刷新）；toggle 全程互斥锁（先查再写非原子，防快速连点重复插入）。

## 9. 风险与真机验证清单（v2 口径）

结构性风险（设计层已建模，真机复核）：

- **续选会话与 pageVersion 清态的挂起**：翻页不清选区的窗口期内，宿主推来的非续选
  重排（如追更）不得撕裂会话。
- **AAR 版本分栈**：破坏性契约变更随 minor 升级，宿主与模块版本配套按发布纪律更新。
- **保存定位兜底（实施精化，v2.2）**：模块提交的是「页内坐标 + 选中原文」，宿主
  按提示位在前 256 / 回搜 `max(256, 原文长)` 内定位；提示位漂移超出窗口时真机
  反馈「写想法保存失败」。现补两条兜底——① 宿主重排（`clearTextChapter` →
  异步 `loadContent`）期间内容窗口短暂为空时**有界等待**正文就绪（≤1.5s）再判
  失败；② 窗口内定位失败后追加**全文唯一命中**兜底（唯一即无歧义；0 次/多次
  仍从严返回失效）。定位失败/内容未就绪/无会话书三类失败分别写 `AppLog`
  （`eink saveMarking: …`），便于真机定位。

真机手工清单（v2.2 全量）：

1. **选中态观感**：长按/拖拽期灰底选中带贴合行盒（不漏行、不越界）、两侧
   pin 把手高度与文本行高一致、把手热区易抓取；拖动期刷新波形与残影。
2. **松手弹操作条**：圆角卡片三键（图标在上、文案在下）锚在选区上/下方不越界；
   新区间 复制/想法/画线；已有标记 复制/想法/删除；含标题选区只留复制。
3. **调界交互**：按住把手操作条隐藏、抬手回来；把手前拖越过起点时区间与把手
   正确换边（起点终点翻转）；抬手后操作条重新锚定不跳位。
4. **画线**：落库后为黑色实线；从「选好区间」到「线稳定呈现」全程无闪断
   （选中带续显到装饰在位）、正文不重排不跳页、宿主定位命中；
   完整模式打开同一标记显示同样为黑实线。
5. **想法**：顶部大弹框 + 自动拉起输入法（新建/编辑同一份，编辑预填内容）；
   长内容向上滚动不挤压弹框；取消回到操作条态；保存后转虚线、同锚点 upsert
   不产生第二条标记；**内容清空保存则变回实线划线**。
6. **操作条收取**：点非按钮区域即收操作条（选区态另清选区）且不翻页、不唤
   阅读菜单；收操作条后再点标记可重开；落库窗口内的残留选区点按只清选区。
7. **点按已有标记**：划线与想法都先弹同一操作条三键，想法键再开编辑更新弹框
   （与「选区落在标记上」入口的弹框形态/内容一致）；标记失效（换源清理）
   静默回落分区行为。
8. **跨页双向续选**：多页累计、跨段落/跨标题边界拼接、前向翻页后反向再翻
   （越出边归属）、松手合成完整章内区间且宿主定位命中。
9. **触发带**：页顶/页底按住触发翻页的端点吸附与跟手性；正常拖拽调界、行盒
   间空档、空白区长按拖拽死手势不得误触发。
10. **目录页三段**：标题下 目录/书签/笔记 切换（默认目录）；书签/笔记按章节
    聚合（章节头 = 章名 + 条数，当前章加粗 + 左侧标记）；卡片第一行只有
