# 纯净阅读模式（E-Ink）配置生效清单

> **文档目的**：纯净阅读模式完整复用完整模式（View 版）的所有用户配置，但使用新的 Compose 界面，仅开放部分必要设置。本文档枚举完整模式下**所有需要 UI 界面响应才能生效的配置**，作为纯净阅读模式"需实现配置"与"允许修改配置范围"筛选的依据，并在后续设计与实现变更时持续更新。
>
> **范围边界**：仅收录配置变更后需要阅读界面（或其承载的窗口 / 系统栏）做出反应的项——重新分页、重绘画笔、布局重排、切换交互代理、调整窗口属性。纯引擎 / 业务层自动生效的配置（缓存、预下载、换源、TTS 等）不收录，见 [F. 排除清单](#f-排除清单非-ui-层生效)。
>
> **维护规则**：任何涉及阅读配置的消费链路变更（View 版设置对话框、`ChapterProvider` / `TextChapterLayout`、E-Ink `ReaderViewModel` / `ReaderScreen`、`ReadBookConfig` 字段增删）合入时，须同步更新本文档对应条目与文末变更记录。

## 1. View 版生效机制参考模型

View 版阅读页没有逐字段观察者。所有配置变更由各设置对话框写完 `ReadBookConfig` 后 `postEvent(EventBus.UP_CONFIG, [动作码])`，`ReadBookActivity.observeLiveBus()`（`app/src/main/java/io/legado/app/ui/book/read/ReadBookActivity.kt:1640`）统一消费。动作码决定每项配置的生效级别，是后文"生效级别"归类的依据：

| 动作码 | 响应 | 生效级别 |
|---|---|---|
| 5 | `ReadBook.loadContent(false)` 重新排版分页 | **重分页**（最重） |
| 10 + 5 | `ChapterProvider.upLayout()` + 重分页 | 重分页 |
| 8 / 9 / 11 | 重建画笔 + CanvasRecorder 缓存失效 + 重新预渲染 | **重绘** |
| 1 / 3 | 背景 Drawable 重建 / 背景透明度 | 重绘 |
| 2 / 6 | 页眉页脚样式 / 内容重排 | 重绘 / 布局 |
| 0 | 系统栏（沉浸式 / 状态栏图标深浅） | Window 级 |
| 12 | `upPageAnim()` 切换翻页代理 | 交互级 |
| 4 | 翻页触摸阈值 | 交互级 |

配置存储分两类：

- **readConfig.json**（`ReadBookConfig.Config`，内存对象 + 异步落盘，`files/readConfig.json`）：排版参数、颜色背景、页眉页脚等，即"样式方案"内容。
- **SharedPreferences**（`AppConfig` / `ReadBookConfig` 顶层属性，PreferKey）：行为开关、对齐开关、屏幕方向等全局项。

`ReadBookConfig.Config` 中颜色 / 背景 / 翻页动画 / 状态栏图标各有日间、夜间、E-Ink 三套变体，取值分支由 `AppConfig.isEInkMode`（`themeMode == "3"` E-Ink 配色 / `"4"` 纯净阅读）与 `AppConfig.isNightTheme` 决定（`help/config/ReadBookConfig.kt` 的 `curTextColor()` / `curBgStr()` / `curPageAnim()` / `curStatusIconDark()` 等）。

## 3. E-Ink 纯净阅读侧现状基线

架构：E-Ink 阅读器完全复用 View 版排版引擎 `ChapterProvider` + `TextPage` + `ReadBook` 全局状态机，排版参数直接读写共享的 `ReadBookConfig`（同一份 readConfig.json）。改参后 `ChapterProvider.upStyle()` + 200ms 防抖 `relayoutEngine()`（清缓存重排），见 `app/src/main/java/io/legado/app/eink/reader/ReaderViewModel.kt:596` 起。

### 3.1 已接入

| 类别 | 项目 | 位置 |
|---|---|---|
| A 类子集 | `textSize` / `letterSpacing` / `lineSpacingExtra` / `paragraphSpacing` / `paragraphIndent` / 正文四向 `padding*` | `ReaderViewModel.kt`（阅读内排版面板 + 边距弹框）；`eink/settings/SettingsViewModel.kt`（全局设置页，已决策移除，见 3.3） |
| A 类（快照） | `headerPadding*` / `footerPadding*` | `ReaderViewModel.kt:533-570`，仅快照生效，不影响分页 |
| A7 | `textBold`（0/1 切换） | `ReaderViewModel.kt:573` |
| B1（间接） | 正文色经 `isEInkMode` 分支走 `textColorEInk` → `ChapterProvider` 画笔 | 引擎自动（已决策主动屏蔽，固定黑字，见 4.2） |
| B2（部分） | `bgStrEInk` / `bgTypeEInk`：仅 `bgTypeEInk == 0`（纯色）时取色，否则回退纯白 | `ReaderScreen.kt:214-223`（已决策主动屏蔽，固定白底，见 4.2） |

阅读内设置面板（`ReaderMenus.kt`）：排版（字号 / 字距 / 缩进 / 行距 / 段距 / 边距调整弹框）、其它（屏幕常亮 / 正文加粗 / 自动翻页间隔 5-120s）、缓存（后 50 / 100 / 200 章 / 全本）。全局设置页（`eink/settings/`）：排版 + 边距 + 恢复默认值（已决策移除，见 3.3）。

### 3.3 已知问题与处理决策

1. **全局设置页不落盘**：`eink/settings/SettingsViewModel.persist()` 修改 `ReadBookConfig` 后未调用 `ReadBookConfig.save()`，仅内存生效（阅读内 `ReaderViewModel` 有 save，行为不一致）。
   处理决策：**移除全局设置页**（`eink/settings/` 界面已不需要，入口一并清理），落盘不一致问题随之消除。待实现。
2. **背景色不自动刷新**：`ReaderScreen.kt` 中背景色 `remember{}` 无 key，配置变更后不会自动 recompose。
   处理决策：**屏蔽背景色变化**——纯净模式不支持设置背景，正文区固定白底（联动 4.2 B2 主动屏蔽决策），`remember{}` 缓存问题随之消除。待实现。
3. **状态栏图标脱离配置体系**：`EinkMainActivity` / `EInkRoot` 按主题背景亮度决定 `isAppearanceLightStatusBars`，不消费 `darkStatusIconEInk`。
   处理决策：**屏蔽 `darkStatusIconEInk`**，默认只支持亮色状态栏（固定浅色底、深色图标），不从配置读取（联动 4.2 B7 主动屏蔽决策）。待实现。

### 4.3 交互模型改进（决策背景，待实现）

E-Ink 侧现有交互模型需要改进，是 E1 / E6 决策的直接背景：

1. **点击分区：三分区 → 九分区**。现状为左 30% 上一页 / 右 30% 下一页 / 中间 40% 唤出操作条（`ReaderScreen.kt:242`），改为九分区（对齐 View 版 `clickActionTL..BR` 九宫格动作映射，对应 E1）。
