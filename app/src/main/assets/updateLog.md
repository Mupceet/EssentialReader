# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新合并上游完整模式的听书悬浮胶囊、书架副本管理等大批更新，墨水屏模式落地首屏封面预热并修复多项阅读与换源细节。

### 新增

* 墨水屏模式：书架首屏封面预热——进入墨水屏模式即后台预载第一页封面，冷启动书架少一轮「文字占位→封面到位」的全页重绘
* 墨水屏模式：阅读页眉时间按分钟自动走字（此前仅随翻页刷新），电量显示随之更新
* 完整模式：听书/有声书全局悬浮胶囊与播放器改版——悬浮窗与主页悬浮底栏两种模式下的胶囊布局，胶囊支持长按操作
* 完整模式：书架副本管理——加入书架时提示同名同作者疑似重复，删除已入架书籍时展示并跳转其他副本，「书架操作」Sheet 集中副本/分组/删除
* 完整模式：换源保留选项新增「作者」（墨水屏换源走宿主同管线，同样生效）

### 修复

* 墨水屏模式：修复阅读页脚长章节标题下缘被裁切的问题
* 墨水屏模式：修复目录页持续缓存新书时缓存角标不更新的问题
* 墨水屏模式：云端进度同步同章位置微差不再重复弹确认框
* 墨水屏模式：换源默认删除旧源已下载章节缓存，避免沿用坏正文；目录拉取与首章正文错峰请求，降低书源限流导致的首次加载失败
* 完整模式：修复朗读两处崩溃
* 完整模式：修复阅读记录跨午夜时长统计与会话删除问题
* 完整模式：修复阅读菜单云端进度入口因初始化时序而不显示的问题
* 完整模式：漫画阅读修复一批（区域解码、显式下载保留、阅读进度保持、条漫分块渲染）

### 优化

* 完整模式：启动速度与章节排版性能优化，启动基线配置更新
* 墨水屏模式：阅读记录会话导入改内存集判重，大备份导入显著提速
* 构建工具链升级（Gradle 9.8 / AGP 9.4.1）

### 说明

* 私密功能现在默认关闭，可在完整模式设置中开启
* 隐私模式仅在完整模式生效，墨水屏模式暂未适配：墨水屏书架与阅读不经过隐私验证与遮挡
