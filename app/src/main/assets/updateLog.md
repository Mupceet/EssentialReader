# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：翻页方式有了统一设置页（音量键/滚轮/自定义按键）；合并了上游大量更新（阅读更省内存、EPUB 排版增强、主题管理等）；修复讯飞 Cube2 启动闪退。

### 新增

* 翻页设置页：「我的 → 翻页设置」统一管理音量键、滚轮、自定义按键三种翻页方式
  * 自定义按键支持按下即录入、待定键对、逐个移除，保存即生效，页面附实时预览
  * 阅读菜单「其它设置」中的音量键翻页开关移除，统一到本设置页
* 阅读主题管理：阅读菜单中的主题列表支持网格/流式切换、搜索、拖动排序、多选管理与批量导入导出
* 启动自动检查更新：有新版本时启动即提示；「其它设置」中可选择更新来源（自动/GitHub 直连/国内镜像），自动模式先直连、失败自动换镜像
* 段评气泡：书源提供段评（章节气泡数字）时可在阅读界面显示，阅读菜单「其它设置 → 显示段评气泡」可开关
* 高亮样式新增边框描边，可为不同高亮规则设置颜色、粗细、圆角
* 缓存维护：设置 → 下载缓存设置中可清理失效的章节缓存、补全书目字数统计
* 书籍详情页：作者、分类标签可点击跳转搜索；无关联书籍规则时按作者搜索兜底
* 书架网格新增两种自适应模式：固定列数 / 固定封面宽度，按需切换

### 优化

* 阅读更省内存更流畅：打开大部头、翻页排版的内存占用与速度显著改善（分页引擎重构优化）
* 批量导入大量书籍不再卡顿卡死，导入期间书架可正常操作
* EPUB / MOBI 书籍的粗体、斜体、列表缩进等排版样式现在能正确显示
* 离线缓存全新整理：缓存弹窗显示缓存范围与待缓存章数，只缓存未下载的章节，不再重复计数

### 修复

* 讯飞 EBook Cube2 墨水屏模式启动闪退（定制系统字体兼容问题）
* 多设备共用备份不再越恢复越乱：同一本书换过源后不会再出现「同名不同源」的重复条目；在其他设备换源的结果会同步过来（只跟随有阅读进度且比本机新的记录，本机更新不会丢）
* 排版细节：英文单词不再被拆开断行，行首开括号与引号随单词整体换行，行尾标点不再超出屏幕边缘，下划线不再被裁掉
* EPUB：跨章首图不再留白，滚动模式图片加载后不再残留灰块
* 听书：多角色配音的角色分配更准（旧角色回归能认出来）；预取与连播接续更顺
* 升级版本后内置词典、朗读源等默认数据不再漏更新；内置词典更换为汉典（原百度汉语已失效）
* 界面使用自定义字体时，加粗文字不再变细，切换字体、冷启动更顺滑
