# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17（预发布）

本次更新集中完善墨水屏阅读器的排版、字体与阅读性能：

### 新增

* 排版面板新增「字体配置」：可选择系统默认、系统衬线、系统等宽或字体文件夹中的字体；正文与标题字重支持细体、常规、粗体，也可自定义粗细
* 排版面板新增「信息配置」：可设置标题位置与字号、页眉显示方式（显示 / 隐藏 / 随状态栏）、页脚显隐，以及页眉页脚统一字号
* 页眉页脚字体与正文、标题统一，字号、边距等调整可在阅读页实时预览
* 「正文加粗」开关并入字体配置中的字重设置

### 优化

* 提前准备相邻章节，并优先显示当前阅读章节，跨章翻页更快
* 从书架进入书籍时提前加载内容，减少首次打开阅读页的等待
* 优化目录打开和返回阅读页的速度，重复进入目录更流畅
* 从目录返回阅读页时直接恢复原内容，减少“先加载中再恢复”的等待
* 调整页眉页脚占用空间，使墨水屏模式的每页行数和页数与完整模式保持一致
* 统一排版面板及字体、信息弹层的文字样式和控件间距，显示更整齐

## 3.26.16（首个版本）

基于 legado 开源项目与 MD3 界面移植构建，加入墨水屏专属阅读模式：

* **墨水屏模式**：轻量单界面（书架 / 搜索 / 阅读），黑白主题跟随系统深浅色，音量键翻页，页眉页脚信息条
* **完整模式**：MD3 风格全功能界面，导入导出、书源管理、Web 服务等管理能力均在此完成
* 排版设置两种模式共享——任一模式调字号、行距，另一模式同样生效
* 墨水屏模式入口在「我的 → 实验室」，可设为启动直达

## 温馨提醒

* 本应用只是转码工具，不提供内容；书源需要自行导入，可使用 legado 生态的书源资源
* 更新前建议先做好备份，以免数据丢失

## 已知限制

* 墨水屏模式功能持续完善中，遇到问题可随时切换回完整模式
