# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta.6（预发布）

本次更新为墨水屏阅读界面带来划线、想法与书签：

### 新增

* 长按选中文字即可划线：选中范围带灰底、两端出现可拖动的把手，松手后弹出「复制 / 想法 / 画线」操作条，划线默认为黑色实线
* 长按选中文字后可直接写想法，顶部弹框自动拉起输入法；想法内容留空保存会自动变回纯划线
* 点一下已经划好的线或想法，可以修改想法、删除标记或复制原文
* 支持跨页续选：按住页顶或页底可把选区扩展到上一页/下一页，跨页划线一次完成
* 页面书签：顶栏书签按钮（未加书签显示加号、已加书签显示减号）与阅读区下拉手势都能给当前页加/去书签，带书签的页面显示书签折角
* 目录页在标题下新增「目录 / 书签 / 笔记」三个标签，书签与笔记按章节聚合展示，点卡片直接跳回书中位置；内容随阅读预先读取，打开即显示
* 笔记支持一键导出为 Markdown 文件
