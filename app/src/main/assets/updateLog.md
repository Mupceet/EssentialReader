# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新为墨水屏阅读界面带来云端进度同步与段评查看：

### 新增

* 云端进度同步：进入/退出阅读时自动与 WebDAV 云端同步阅读进度，云端进度比本地新时会先询问再恢复，换设备接着读不用手动找位置
* 「我的」页新增「同步阅读进度」开关，与完整模式同键共享，随时开关同步
* 段评查看：书源支持段评的书，点正文里的段评气泡可以打开评论页；底部「上一页 / 关闭 / 下一页」控制条按半屏步进翻页，上下文连着看；评论页进出即时无过渡动画，墨水屏不残留
