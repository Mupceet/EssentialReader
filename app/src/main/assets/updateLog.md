# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta.5（预发布）

本次更新为墨水屏书架新增样式设置面板：

### 新增

* 书架顶栏新增样式设置入口，打开后可在墨水屏模式内直接调整书架样式，无需前往完整模式
* 面板可切换书架布局（网格/列表），并可设置未读角标、新章高亮的显示与隐藏
* 网格布局下可拖动滑条调整封面宽度和书名行数，列表布局下可开关最新章节行
* 每项调整立即生效并按新样式重新计算每页显示数量，同时同步到完整模式，两种模式的书架设置保持一致

### 优化

* 原顶栏布局切换按钮并入样式面板，切换底部标签页时面板自动收起
* 阅读页排版入口与书架样式入口更换新图标
