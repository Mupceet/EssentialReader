# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新为墨水屏模式新增阅读正文简繁转换，并修复恢复备份同名书籍合并与大批量导入内存溢出两处问题。

### 新增

* 墨水屏模式：阅读正文简繁转换——排版「字体配置」弹窗新增三档（关闭/繁转简/简转繁），点选即生效并重排当前章；与完整模式排版设置的「简繁转换」共享同一存储，两侧任改全局一致

### 修复

* 备份恢复：合并时识别同名在线书的三种形状——跨设备恢复不再堆积同名多本，换源产生的书籍变更可随备份快照传播到其他设备
* 完整模式：修复批量导入大量书籍（数千本量级）时的内存溢出——导入改分块事务提交压低数据库失效风暴，书架与导入页列表刷新加防抖兜底
