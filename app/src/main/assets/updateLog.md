# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：阅读界面新增书源信息行，可直达书源登录与付费章节购买；墨水屏页眉页脚更清爽。

### 新增

* 阅读界面可显示书源信息：在阅读菜单「其它设置」中开启「显示书源信息」（默认关闭）后，顶栏下方一行显示当前章节名与所读书源名
  * 书源需要登录或章节需要付费时，点击书源名可展开操作：「书源登录」直达登录页面，「购买本章」完成购买后自动重新加载本章
  * 换源后书源信息随之刷新

### 调整

* 墨水屏阅读界面与屏保的页眉、页脚不再显示分隔线，页面更清爽；排版与翻页位置不受影响
