# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：合并上游大量更新（设置搜索、跨页选择文字、高亮夜间颜色、Markdown 本地书、漫画导出等）；多设备备份恢复策略调整为保留本机。

### 新增

* 设置页新增搜索：输入关键词直接定位到对应设置项，不用层层翻找
* 本地书新增 Markdown 格式：正文排版、图片、链接可直接阅读
* 高亮规则支持白天/夜间两套颜色，夜间阅读高亮不再刺眼
* 长按选择文字支持跨页延续，选中范围不再被一页截断（可在设置中开关）
* 阅读外观（主题、字号等）对本地 EPUB / MOBI 书籍同样生效
* 段评弹窗高度可调节，小屏也能舒展看评论
* 本地漫画支持导出为图片文件夹或 CBZ 文件
* 完整模式新增 Mochi / Miuix / HyperOS 4 等主题家族，外观选择更丰富

### 优化

* 保存正文图片不再卡住界面，大图保存也顺滑
* 横屏阅读时正文避开侧边手势条，不再被遮挡
* 仿真翻页渲染更省资源

### 修复

* 多设备共用备份更保守：恢复时一律保留本机已有的书，不再按备份里较新的记录删除本机条目
* 听书：离线下载的语音优先播放；下载中途出错不再丢失已完成的音频；朗读出错时停在读到的句子，恢复后从原句继续
* 快速连续切换书籍时，上一本的阅读进度不再串写到新书
* 视频书源：全屏播放切换剧集不再退出全屏；支持播放本地视频文件
* 缓存维护运行中可以随时取消，取消后进度不再错乱
