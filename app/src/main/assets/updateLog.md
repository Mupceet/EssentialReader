# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新让段评气泡可以一键隐藏，并为墨水屏阅读带来可自定义的点击区域：

### 新增

* 阅读设置新增「段评气泡」开关：默认开启；关闭后段评气泡不再排版显示，正文更清爽（完整模式与墨水屏模式一致生效，墨水屏也可在「其它设置」面板直接切换）
* 墨水屏阅读页新增「点击区域设置」（其它设置面板进入）：九宫格点按分区可自定义——中心固定唤出菜单，其余各格在上一页/下一页间切换，退出设置即生效

### 修复

* 修复关闭段评气泡后，气泡所在行残留空行的问题
