# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：无封面书籍的文字封面全新设计；多项阅读与屏保显示修复。

### 新增

* 无封面书籍的文字封面全新设计：
  * 书名以竖排「题签」呈现在封面左上，右下配作者名与书名首字藏书印，整洁美观、更具书卷气
  * 封面文字与界面字体保持一致
  * 过长的书名自动省略，不再挤满整个封面；书名中的【标签】以小字呈现，括号副标题不再上封面

### 修复

* 阅读器：
  * 页眉时间/电量与页脚页码不再超出屏幕边缘，页脚字号与阅读设置一致
  * 在两种阅读界面之间切换时，页面内容位置不再跳动
* 屏保：屏保图按设备真实屏幕尺寸生成，不再拉伸变形
* 书架：搜索历史条目排版修复，不再异常拥挤
