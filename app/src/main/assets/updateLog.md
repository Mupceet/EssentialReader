# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：目录页的书签、笔记可以直接删除，左右滑动即可在「目录」「书签」「笔记」之间切换；修复阅读时长统计偏多的问题；多台设备共用同一备份时，各自的界面与显示设置互不覆盖。

### 新增

* 墨水屏模式目录页：书签、笔记卡片的时间行新增「删除」按钮，按一下即可删除，不再需要进入书籍逐个清理

* 墨水屏模式目录页：支持左右滑动，在「目录」「书签」「笔记」三个页面之间快速切换

* 墨水屏模式的界面偏好（阅读点击分区、下拉添加书签、翻页水波纹档位）现在随备份一起保存，重装恢复后无需重新设置

### 修复

* 修复阅读时长统计偏多的问题：应用被系统冻结期间的间隙不再被计入阅读时间，每日阅读时长恢复真实

### 优化

* 多台设备共用同一备份时，设备相关的设置互不覆盖——「墨水屏模式」开关、书架列宽、界面字体大小、阅读亮度等只跟随设备本身；从另一台设备恢复备份不会再把它们改掉，重装后恢复本机备份则可原样找回

* 提示：重装后想找回上述设置，恢复前请先把备份设置中的「设备名」设成与之前一致
