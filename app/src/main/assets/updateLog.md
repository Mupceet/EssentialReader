# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：墨水屏书架支持分组——长按书籍即可归组，分组以封面拼贴卡片展示，点开即看组内书单；筛选器可自行挑选与排序；记住你最后浏览的位置，下次打开接着看。

### 新增

* 书架分组：长按书籍选择「加入分组」，一本书可同时属于多个分组；分组以封面拼贴卡片展示在书架顶部，点击进入组内书单，列表样式下还能直接预览组内书名

* 分组管理：长按分组卡片可重命名、解散或调整顺序；暂时不用的分组可隐藏，需要时再打开

* 筛选器管理：书架右上角筛选菜单可自行挑选（在读、未读等）、排序、显示隐藏，只留常用的

* 记住浏览位置：上次选的筛选或进入的分组，下次打开应用自动恢复

* 书架设置新增「支持分组展示」开关（默认关闭）：不需要分组的用户保持原有简洁书架，开启后长按书籍才出现分组操作

* 书籍详情页：作者下方显示书源，点击可直接换源

* 换源时顶部实时显示搜索进度「进度 n/m」

### 修复

* 修复自定义界面字体后标题不加粗的问题
