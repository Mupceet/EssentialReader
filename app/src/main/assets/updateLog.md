# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：墨水屏模式支持高亮规则渲染——完整模式配置的对话、书名号等规则样式在墨水屏上按灰度呈现，修改规则即时生效。

### 新增

* 墨水屏模式渲染高亮规则（规则编辑仍在完整模式进行，数据两模式实时互通）
* 规则样式支持（彩色一律按灰度呈现，保留透明度）：
  * 字色、背景色、下划线颜色
  * 下划线款式六种：实线 / 虚线 / 波浪 / 双线 / 删除线 / 荧光笔
  * 下划线粗细、与文字的距离（虚线节距、波浪幅度、双线间距同步支持）
  * 自定义字体、字重、斜体、字号偏移
  * 命中字距（前/后）、命中行行距（上/下）
* 暂不支持：SVG 花色下划线（显示为实线）、背景图气泡（平铺/拉伸/裁剪/九宫格）、多角色对话气泡

### 修复

* 删除线、荧光笔两种下划线款式此前在墨水屏被画成普通实线下划线
* 带字体/字号偏移的规则文字与排版留宽不匹配（字画不满自己的位置，段间出现多余空隙）
* 命中字距的段前留白被并入首字：高亮带、下划线与长按选区不再盖到空白上
