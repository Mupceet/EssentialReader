# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新为墨水屏模式新增阅读正文简繁转换，并修复恢复备份与批量导入的两处问题。

### 新增

* 墨水屏模式：阅读正文支持简繁转换——在「排版 → 字体配置」中选择 关闭/繁转简/简转繁，点选后正文立即切换；与完整模式里同一个设置互通，改哪边两边都生效

### 修复

* 恢复备份：从备份恢复时，同一本书不再因为来源不同被重复添加成多本；在一台设备上换过源的书，恢复到其他设备后仍保持换源后的结果
* 完整模式：修复一次性导入大量书籍（几千本）时可能闪退的问题
