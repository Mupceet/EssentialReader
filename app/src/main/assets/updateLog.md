# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新「音量键翻页」扩展为全局翻页——书架、目录、搜索结果等列表里，音量键与翻页器同样可以翻页；阅读菜单的设置面板完整展开，不再需要滚动才能点到按钮；打开缓存面板时顶部操作栏保持可见。

### 新增

* 「音量键翻页」扩展到全部可翻页列表——书架、目录、搜索结果、换源、书籍详情、字体设置等界面同样可用音量键或翻页器整页翻动；「我的」页新增「音量键翻页」开关，与阅读界面「其它设置」中的开关联动，一处设置全局生效

* 弹出窗口（如确认框、想法编辑、边距调整）打开期间，音量键自动恢复为调节音量，不会在窗口背后继续翻页

### 修复

* 墨水屏模式：修复阅读菜单「排版设置」等面板底部按钮显示不全、需要滚动才能点到的问题——面板现在完整展开

### 优化

* 墨水屏模式：打开「缓存」面板时顶部操作栏不再消失——书签、换源、刷新、缓存按钮保持可见可点
