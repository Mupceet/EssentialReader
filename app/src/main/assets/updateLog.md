# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta.7（预发布）

本次更新完善墨水屏阅读界面的划线、想法与书签，并修好一批实机反馈的问题：

### 新增

* 墨水屏界面接入「外观字体」设置：在设置里更换字体后，墨水屏的书架、目录、样式面板等界面文字同步生效

### 优化

* 墨水屏界面文字档位重排：正文、书名、按钮与列表信息的字号字重统一成一套阶梯，大字体倍率下书架列表行高不再被截断
* 目录页顶部「目录 / 书签 / 笔记」改为无边框文字标签：选中项用黑色下划线标注、文字加粗，点按不再整块反色
* 跨页续选更顺手：向下选到页底、向上翻回上一页都能接着扩选，手指往回收能收窄范围，越过起点后区间收成「移动端 → 起点」，与单页内反向拖动一致

### 修复

* 修复跨页选择时范围错乱、翻到下一页后翻不回上一页，以及拖动过程中闪退的问题
* 修复从笔记列表点开一条笔记、修改想法后提示「保存失败」的问题
* 修复跨段选择时段首缩进也被灰底和下划线覆盖的问题
* 修复备份与恢复不包含划线笔记（book_marks）的问题
* 修复阅读界面切换深色 / 浅色后不立即生效的问题
