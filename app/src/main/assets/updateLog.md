# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：合并上游 legado-with-MD3 至 2026-10-20 主线（132 项提交）——阅读排版、缓存与备份、局域网访问、字体管理全面升级。

### 新增

* 按书关闭阅读记录：完整模式书详情可为单本书关闭阅读时长统计，墨水屏阅读同样生效
* 字体直接导入：系统文件选择器读不出字体目录的设备可直接导入字体文件；墨水屏字体列表同时并入已导入字体，同名以所选文件夹优先
* Android 17 本地网络权限引导：墨水屏模式访问局域网 WebDAV、书源被系统拦截时自动弹出授权，不再静默超时
* 完整模式：预下载拆分「向前 / 向后」（向前默认 0 不再抓上一章）、发现页跳转页码、书架标签来源设置、自定义顶栏按钮、平板与折叠屏分屏、听书与阅读可同时进行

### 修复

* 阅读排版（墨水屏同步受益）：英文换行不再吞词尾空格；整串标点不再把一行顶出空洞；长章节阅读内存优化；字号兼容
* 升级后旧章节缓存不再失效；章节正文与图片缓存按章重组；朗读音色随备份保留
* file:// 路径字体可用；字体文件夹读不出时说明原因
* 阅读器 RectList 崩溃（Compose 升级至 1.13.0-beta01）
* 听书与朗读：HTTP 朗读断流卡顿、段落间隔重复合成、多角色配音系列修复（完整模式）
