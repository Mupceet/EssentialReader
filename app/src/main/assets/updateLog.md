# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新重做墨水屏模式入口——「我的」页一键开关即达，并同步上游完整模式的修复与优化：

### 新增

* 「我的」页顶部新增「墨水屏模式」开关：打开即进入墨水屏界面，退出时自动关闭；开关打开期间冷启动自动回到墨水屏（条目显隐由实验室「启用实验室」+「墨水屏显示」双开关控制）
* 升级迁移：原实验室「墨水屏显示」的开启状态自动继承为新模式开关状态，存量用户冷启动行为不变

### 优化

* 实验室「墨水屏显示」开关回归上游行为：打开只保存偏好，不再直接切换界面，也不再强制切换「电子书」主题；「电子书」主题在主题列表的显隐恢复上游门控
* 同步上游：封面持久化缓存与离线加载、目录字数统计剔除富文本、书架滚动性能、书源管理删除确认与操作提示、AI 朗读推理级别开关（默认关闭思考）、全文搜索历史只记录确认过的查询、听书界面改版等
* 恢复与上游一致的系统版本要求：minSdk 回到 26（Android 8.0）

### 修复

* 修复 Rhino 脚本入口未先安装上下文工厂时，书源登录页脚本执行崩溃的问题（上游 #2258）
