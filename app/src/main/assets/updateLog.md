# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新：掌阅定制机型支持阅读锁屏——息屏后锁屏壁纸自动变成当前在读的书；同时修复墨水屏书架分组的几处使用问题。

### 新增

* 阅读锁屏（掌阅定制机型）：跟随设备的锁屏显示设置，息屏后系统锁屏壁纸自动显示当前在读的书，封面样式会自动优先加载清晰大图

### 修复

* 完整模式中设为私密的分组，不会再出现在墨水屏书架和分组列表里，也不会因上次的浏览位置被带出

* 打开调整分组、筛选菜单或书架样式面板时，音量键不再误翻面板背后的书架页

* 在这些面板里按返回键，会先收起面板并保存调整，不再直接退出应用

* 存储写入异常时切换筛选、进出分组可能闪退——已加固

* 字体设置面板的行距与滑条对齐细节修正
