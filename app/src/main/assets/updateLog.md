# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta.4（预发布）

本次更新主要完善墨水屏书架：

### 新增

* 书架顶部新增布局切换按钮，可在网格和列表之间快速切换，选择结果会同步到完整模式
* 墨水屏书架跟随完整模式的排序方式和升降序设置
* 书架显示同步完整模式设置，包括未读角标、新章节高亮、列表最新章节和默认布局
* 网格封面大小跟随完整模式的封面宽度设置，并随屏幕宽度和旋转自动调整列数
* 网格书架标题行数跟随完整模式的标题最大行数设置，支持显示 1–5 行，行数变化后自动重新计算每页显示数量

### 优化

* 书架列表行高会随字体大小调整，放大字体后文字不再被截断，封面也同步放大
* 章节内容会提前下载；离开书架后，已经开始的下载不会中断
* 刷新书架时，每本书完成更新后立即开始下载章节内容，减少进入书籍时的等待
* 旋转屏幕或调整字体大小后，书架会按新的布局重新计算每页显示数量

### 修复

* 修复字体放大后阅读界面的页脚和设置滑块显示不完整的问题
* 修复字体放大后书架列表文字被截断、封面偏小的问题

## 3.26.16（首个版本）

基于 legado 开源项目与 MD3 界面移植构建，加入墨水屏专属阅读模式：

* **墨水屏模式**：轻量单界面（书架 / 搜索 / 阅读），黑白主题跟随系统深浅色，音量键翻页，页眉页脚信息条
* **完整模式**：MD3 风格全功能界面，导入导出、书源管理、Web 服务等管理能力均在此完成
* 排版设置两种模式共享——任一模式调字号、行距，另一模式同样生效
* 墨水屏模式入口在「我的 → 实验室」，可设为启动直达

## 温馨提醒

* 本应用只是转码工具，不提供内容；书源需要自行导入，可使用 legado 生态的书源资源
* 更新前建议先做好备份，以免数据丢失

## 已知限制

* 墨水屏模式功能持续完善中，遇到问题可随时切换回完整模式
