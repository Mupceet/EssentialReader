# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新换上全新「墨本」圆章图标，并让多源搜索更省心：

### 新增

* 全新应用图标：「墨本」纯黑白圆章，桌面默认朱文印；应用内「换图标」可选白文印，Android 13+ 主题图标也一并换新

### 优化

* 多源搜索更省电：离开搜索页自动挂起剩余书源的搜索，返回自动接着搜
* 换源选中结果后立即返回，其余书源的搜索同时中止，不用等落选源跑完

### 修复

* 修复个别书源执行 JS 脚本时闪退的问题
* 修复搜索结果重排后页首未对齐、已收录条目升到顶部却看不见的问题
