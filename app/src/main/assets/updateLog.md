# 更新日志

墨本阅读——开源阅读 legado 的墨水屏增强发行版：同一本书，两种读法。

## 3.26.17-beta（预发布）

本次更新合并上游完整模式的隐私模式等一批功能与性能更新，墨水屏模式新增云端备份提示并升级换源管线。

### 新增

* 墨水屏模式：启动时检测云端是否有较新备份，确认后恢复并反馈结果
* 完整模式：隐私模式——私密分组与单本私密书：分组内书籍不在公开书架显示、进入需验证；私密书留在书架但封面与文字会被遮挡，验证后显示；支持本地密码与生物识别快捷解锁，可配置验证时机与保持时长
* 完整模式：阅读目录页新增「使用替换规则」开关，可在目录中快速切换替换净化

### 修复

* 完整模式：修复阅读界面偶发不刷新的问题
* 完整模式：修复阅读中电量百分比不刷新的问题

### 优化

* 墨水屏模式：换源改走与完整模式一致的替换管线，备注、缓存目录、阅读时长随书迁移并刷新云端备份，避免从旧备份恢复时带回旧源同名书
* 墨水屏模式：换源搜索逐源结果落库缓存，与完整模式共享
* 完整模式：阅读电量图标改用与旧版一致的电池矢量样式
* 完整模式：启动速度与章节排版性能优化

### 说明

* 隐私模式仅在完整模式生效，墨水屏模式暂未适配：墨水屏书架与阅读不经过隐私验证与遮挡
